# WedFlowLab

> Premium Web Design Studio built exclusively for Wedding Professionals.

High-converting websites that position luxury wedding photographers, videographers, planners, and venues as the uncontested choice.

---

## Tech Stack
- **Framework:** React 19 + TypeScript + Vite
- **Routing:** React Router v7 (with `vercel.json` SPA routing)
- **Styling:** Tailwind CSS v4 + Custom Design System
- **Animation:** CSS Transforms + Motion
- **Media:** Cloudinary Video Slides & Optimized Imagery
- **Booking:** Calendly Integration

---

## Deployment (Vercel)
This repository is configured out-of-the-box for zero-config Vercel deployment:
1. Connect this repository on [Vercel](https://vercel.com).
2. Framework Preset: **Vite**
3. Build Command: `npm run build`
4. Output Directory: `dist`
5. Click **Deploy**.
